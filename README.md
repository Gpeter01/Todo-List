# Todo  List
Welcome y'all, this is a todolist app. *The TodoHub*.

## Key features
- A simple clean ui.
- It enables the use of projects to further organise your todos.
- It provides a theme functionality to make your projects even more visually pleasing.
- It retains todos in storage.
- Date functionality to track todos.
- It also allows the expansion, edit and delete of todos.
- Persistence of page so you can pick up where you left of.
